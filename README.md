# OT Risk & Remediation Decision Engine (OT-RRDE)

**Research prototype v0.1 — synthetic data only.**

This project explores an explainable, safety-aware decision-support method for triaging simulated OT cybersecurity vulnerabilities. It distinguishes investigation urgency from remediation feasibility and does not perform autonomous patching, scanning, or network changes.

The working v0.1 implementation and reproducible tests will be committed to this repository. See `SECURITY.md` for the permitted research-only scope and safety limitations.
