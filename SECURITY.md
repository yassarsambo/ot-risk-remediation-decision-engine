# Security and scope

This repository is a **research-only, offline simulation**. It accepts fictional test fixtures. It is not intended for production OT assets or operational changes and makes no safety, reliability, performance or protection guarantees.

Do not submit actual OT network inventories, equipment configurations, usernames, passwords, vulnerability intelligence from restricted systems, incident records, or other sensitive information in issues or pull requests. Do not scan or modify industrial equipment using this prototype.

The code does **not** patch assets, change firewalls, run network scans, or connect to industrial control systems.

Before contributing any external datasets or real-world case studies, obtain appropriate authorisation and remove identifying or sensitive information.

For potentially sensitive security concerns, avoid posting exploit details or secrets publicly; contact the repository owner privately using their existing GitHub profile contact mechanism when available.
