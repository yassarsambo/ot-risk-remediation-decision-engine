# OT-RRDE reviewer pilot

**Eight fictional OT cases · Pilot form · 16 November 2026**

This exercise tests whether the case descriptions and rating form let OT practitioners make and explain their own judgements. Review each case independently before viewing any engine output or discussion from another reviewer. Use the evidence available as of **12:00 UTC on 16 November 2026**. Each timestamp marks when a record became available to the decision-maker. The dossiers can include later records so their timing can be assessed. All assets, sources and scores are fictional.

## Rating form

For each case, record the following judgements.

1. **Investigation timing.** Choose **immediate** to start human triage now, **prompt** to assess ahead of the routine queue, **scheduled** for normal review, or **insufficient context**. Also flag cases that need immediate attention while facts are gathered.
2. **Acceptable next actions.** Select all that apply. Gather evidence and escalate, plan controlled mitigation and patch review, propose a patch conditional on named prerequisites, or specify another next action. Name any unsafe option and the decisive blocker.
3. **Evidence and uncertainty.** Record the evidence that drove your decision, the most useful missing fact and whether there was enough information to judge timing and next action.
4. **Deployment priority.** Where the evidence supports an applicable, deployable patch, choose **defer**, **scheduled**, **out of cycle** or **immediate** and state any approval your judgement assumes. Mark cases where applicability or readiness is unresolved as outside this question's scope. Use the Deployer definitions for this field.
